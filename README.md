# Customer Order Portal

A demonstration application used to showcase integration between GitHub and ServiceNow DevOps Change Velocity.

## Business Scenario

The Customer Order Portal allows customers to view order information including:

- Order status
- Estimated delivery date
- Carrier information
- Shipment tracking number

## DevOps Demonstration

This repository demonstrates an end-to-end DevOps delivery process using:

- GitHub Issues for development requirements
- GitHub source control for application code
- Pull Requests for controlled code changes
- GitHub Actions for CI/CD automation
- Automated Jest testing
- DEV and TEST deployments
- ServiceNow DevOps Change Velocity for production change governance
- Policy-driven change approval
- Scheduled production deployment
- GitHub production deployment following ServiceNow authorization

## Production Governance

Production deployments are governed through ServiceNow DevOps Change Velocity.

ServiceNow gathers evidence from the development lifecycle and applies change governance before allowing the production deployment to proceed.
